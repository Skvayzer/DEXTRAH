# ADEPT FMB proxy assets

Run `python scripts/generate_adept_fmb_assets.py` to generate the star and
square/round peg–receptacle pairs.

The shapes follow the public FMB object families, but the ADEPT v1 paper does
not publish its simulation CAD, dimensions, mass, or insertion clearance. The
values at the top of the generator are therefore inferred placeholders. Replace
them with measured/CAD values before using these assets as a digital twin.
